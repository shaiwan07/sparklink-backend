VIDEO SHEDUAL PAGE

Notes / Requirements:

  1. Users should be able to see the days and time slots that the other user marked as available, so they can adjust their own availability.
    If needed, users can open additional time slots at the bottom of the screen.
    Once both users provide availability, the system should suggest the earliest possible meeting date and time for both sides.
  2. Users should receive notifications:
    • When a date and time are scheduled
    • And reminders to enter and schedule if they have not done so yet.
  3. Users have 48 hours to set a meeting date and time.
    If they do not, they should receive a notification every 4 hours until scheduling is completed.
  4. The video call must take place inside the app.
    Currently, the link automatically redirects users to an external Zoom call, which should be replaced with an in-app video call experience.
